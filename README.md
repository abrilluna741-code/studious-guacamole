# Proyecto: Playlist Musical (Lista Doblemente Ligada)

Este proyecto implementa un reproductor de música por consola en **C++** utilizando una **lista doblemente ligada** creada desde cero. Cumple con los requerimientos del documento *Tarea 4: Estructuras de Datos y sus Aplicaciones* (agregar canción al final, navegar siguiente/anterior, reproducir actual, eliminar actual y ordenar por artista opcional).

## Compilación y ejecución

```bash
g++ -std=c++17 playlist_doble.cpp -o playlist
./playlist
```

## Menú
- 1) Agregar canción (al final)
- 2) Mostrar playlist completa
- 3) Reproducir actual
- 4) Siguiente (Next)
- 5) Anterior (Prev)
- 6) Eliminar canción actual
- 7) Ordenar por artista (opcional)
- 0) Salir
